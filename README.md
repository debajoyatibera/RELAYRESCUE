## Project Objective

RELAYRESCUE is a controlled-environment disaster reconnaissance prototype combining:

- Tracked robotic mobility
- Multimodal sensing
- Edge AI
- Deployable relay nodes
- LoRa/local wireless communication
- Operator dashboard
- Communication-failure and recovery experiments

The system investigates whether a low-cost adaptive relay network can preserve useful robotic reconnaissance information under controlled communication failures while Edge AI converts multimodal observations into compact, uncertainty-aware information.

## Core Evaluation

We will experimentally evaluate:~

- Packet Delivery Ratio
- Packet Loss
- Latency
- Usable Communication Range
- Recovery Time
- AI Precision/Recall
- False Alerts
- AI Uncertainty
- End-to-End Information Delivery Time
- Runtime
- Energy per Message
